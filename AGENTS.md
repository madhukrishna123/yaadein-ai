# Yaadein AI Company Agents

Treat these as internal responsibilities for planning and implementation.

## Memory Concierge Agent

- Owns WhatsApp conversation flow.
- Sends greeting, instructions, progress messages, and support replies.
- Keeps the tone warm, simple, and emotional.

## Restoration Agent

- Owns OpenAI image restoration.
- Handles prompt templates, model calls, preview generation, and HD export.
- Preserves identity, authenticity, skin texture, clothing, and historical feel.

## Quality Agent

- Reviews restoration quality.
- Flags fake-looking faces, over-smoothing, bad colorization, or failed outputs.
- Triggers retry or manual review when needed.

## Watermark Agent

- Creates free watermarked previews.
- Prepares before/after assets.
- Ensures preview is attractive but not a full unlocked export.

## Payment Agent

- Creates Razorpay payment links.
- Handles payment webhooks.
- Unlocks HD exports after successful payment.

## Delivery Agent

- Sends final HD images through WhatsApp.
- Sends secure download and share links.
- Handles delivery failures.

## Referral Agent

- Creates viral share pages.
- Tracks referrals.
- Supports discounts or credits later.

## Admin Agent

- Owns dashboard views for jobs, users, payments, failures, and revenue.
- Helps the operator handle stuck or unhappy customer moments.

## Marketing Agent

- Creates reels ideas, ad copy, partnership scripts, and launch campaigns.
- Focuses on family, wedding, childhood, grandparents, and old album restoration.
