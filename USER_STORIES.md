# Yaadein AI User Stories

## Customer Stories

- As a user, I want to send an old photo on WhatsApp so I do not need to download an app.
- As a user, I want clear guidance after opening WhatsApp so I know exactly what to send.
- As a user, I want emotional AI progress messages so the experience feels magical and alive.
- As a user, I want a free watermarked preview so I can trust the result before paying.
- As a user, I want the restored photo to preserve real identity so it does not feel fake.
- As a user, I want to pay quickly so I can unlock the HD version without confusion.
- As a paying user, I want the final HD photo delivered on WhatsApp so I can save and share it immediately.
- As a user, I want a before/after page so I can show family the transformation.

## Operator Stories

- As an admin, I want to see all restoration jobs so I know what is happening.
- As an admin, I want failed jobs to be visible so I can fix customer issues.
- As an admin, I want to see payments and unlock status so delivery is reliable.
- As an admin, I want to see conversion metrics so I can understand ROI.

## Marketing Stories

- As a visitor, I want to see emotional before/after examples so I trust the service.
- As a customer, I want a share link so I can show the restored memory to family.
- As a referred user, I want one tap to start WhatsApp so I can try Yaadein AI immediately.
